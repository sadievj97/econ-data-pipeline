# Manual downloads

Some series cannot be fetched automatically (for example, tables from the
Statistics Agency of Uzbekistan). Put those files here, and never edit them
after saving.

For each file, add a note next to it with the same name plus `.source.md`,
for example `uzstat_gdp_2024.xlsx` and `uzstat_gdp_2024.xlsx.source.md`, saying:

- the page or link it came from,
- the date you downloaded it,
- the table name and any options you chose on the website.

The data files stay on this computer (git ignores them); the notes are kept in
git so every manual file can be traced and downloaded again.
